## 📌 Projetos

### 🏦 Banking API

API REST de um sistema bancário desenvolvida com **Java e Spring Boot**, utilizando **PostgreSQL, Spring Data JPA, Hibernate e Spring Security**.

O projeto possui autenticação baseada em **JWT**, armazenamento de senhas utilizando **BCrypt** e operações bancárias como:

* Cadastro de usuários
* Criação automática de conta bancária
* Login e autenticação com JWT
* Consulta de conta
* Depósito
* Saque
* Transferência entre contas
* Histórico de transações
* Validação de dados
* Tratamento global de exceções

🔗 [Ver projeto no GitHub](https://github.com/AndreLuiz2005/banking-api)
